# Images Folder

## Profile Image

Add your profile image here as `profile.jpg` (400x400px or larger, square format recommended).

The image should be:
- High quality (at least 400x400px)
- Square or circular crop
- Professional/personal photo
- Format: JPG, PNG, or WebP
